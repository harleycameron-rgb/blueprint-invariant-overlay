# Announcement — Blueprint Invariant Overlay v1.0.0

Blueprint Invariant Overlay v1.0.0 is now released.

This system provides a dual-invariant measurement framework for testing drift across high-energy facility boundaries. It combines:

- a closed geometric reference (Tusi-couple overlay)
- an open environmental reference (daemon gate)
- a differential drift extractor
- a cryptographically sealed invariant block (IHB)
- a metadata wrapper (SVC)
- a full packaging and publication pipeline

The release includes:
- blueprint image
- SVC metadata wrapper
- invariant hash block
- Sentinel_dot SHA-256
- reference implementations
- validation suite
- full documentation
- packaging manifest

The system is agnostic, bounded, and falsifiable. It supplies a test, not a mechanism.

A DOI will be assigned upon Zenodo deposition.

Independent replication is invited.
