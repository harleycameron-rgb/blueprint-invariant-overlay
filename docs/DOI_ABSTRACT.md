# Abstract — Blueprint Invariant Overlay v1.0.0

Blueprint Invariant Overlay is a dual-invariant measurement framework for testing drift across high-energy facility boundaries. A closed geometric reference (a Tusi-couple overlay with a non-locking 1.37:1 harmonic ratio and a 260-dial invariant) is compared against an open environmental reference (a daemon gate yielding coherence traces, ring events and the H and closure invariants). Their difference, ΔC(s) = C_gate(s) − C_tusi(s), is cleaned of known facility periodic terms and its residual spectrum classified as periodic (null), secular (candidate) or source-flipped (invalid). All traces and invariants are sealed in an Invariant Hash Block with a final Sentinel_dot SHA-256, and bound to the blueprint image through an SVC metadata wrapper. The release includes reference implementations, a validation suite, a replication protocol and a compliance template. The system is agnostic, bounded and falsifiable; it supplies a test, not a mechanism. Independent replication is invited.
